# Kane & Lynch: Dead Men VR — {version}

An unofficial VR mod for the original **Kane & Lynch: Dead Men (2007)** on PC: stereo rendering, positional head tracking, motion-controller weapon aiming, tracked native arms and two-handed support for long guns.

Requires your own copy of the game. The **original Steam edition (App 8080)**, **GOG** and a compatible legacy PC build passed local game tests. Headset and mission coverage is limited. The download contains the mod and its support files.

## Start

Connect the headset through Quest Link / Air Link, Virtual Desktop or SteamVR. Open **KaneLynchVRSettings.cmd**, select the game and matching connection, then choose **Save & play**. The Play shortcut starts the game with your saved settings. Steam starts automatically when required.

Setup installs the mod separately from the game and creates Play/Settings shortcuts. For a portable installation, extract the complete ZIP into a writable folder and keep its files together. Python is needed only for optional video recording.

## Defaults

- **DXVK** renderer; Original and experimental D3D9On12 are alternatives.
- Laser sight on ordinary weapons; their additional native dot/crosshair is off.
- Original crosshair on mounted machine guns; original sniper optic available near your face.
- Wrist HUD and native game hints on. Hold **Y** for the weapon wheel, map and team panel.
- Physical reload on **A** for supported weapons.
- VR cutscenes, diagnostic logging and automatic recording off.

Open **Options → VR Settings** in the game to change physical reload, cutscenes, aiming graphics, mounted mouse aiming and game hints. **Movement** provides smooth/snap turning and stick settings.

## Before playing

**VR cutscenes** can reveal missing off-camera animation because the original scenes were authored for fixed shots. Leave the option off for the original cinematic framing on a virtual screen.

The vehicle-mounted machine-gun sequence near the end of the game is awkward to control in VR. **Options → VR Settings → Mounted Mouse Aim** lets you use a physical mouse while retaining the VR view.

Performance varies by mission, renderer and headset connection. Stutters, visual artifacts and loading crashes remain possible. Read the [known issues](KNOWN-ISSUES.md) before reporting a problem.
